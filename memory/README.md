# AI-WRITABLE: 记忆目录索引

本目录回答"我经历过什么、我偏好什么"。AI **可以追加**内容，格式见各文件的模板区。

## 文件清单

| 文件 | 内容 | 写入方式 |
| --- | --- | --- |
| [decisions.md](decisions.md) | 重要决策记录（含理由与复盘） | 追加 |
| [lessons.md](lessons.md) | 经验教训、踩过的坑 | 追加 |
| [preferences.md](preferences.md) | 长期交互偏好、AI 行为约束 | 追加（谨慎） |

## 写入规则

- 只追加到文件末尾的"记录区"，**不要改写已有条目**
- 每条必须带日期，格式 `### YYYY-MM-DD | 标题`
- 一条记录只讲一件事
- 不确定是否值得记 → 先问我
